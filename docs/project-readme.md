# Last Stand Homestead

An Android-first top-down survival shooter built with Godot 4. Scavenge during five-minute days, turn salvage into walls and turrets, then defend the base through five-minute nights of escalating zombie waves.

## Status

Playable Android vertical slice. Automated gameplay checks and debug Android export are green; physical-device touch acceptance and owner-controlled Play signing remain. See `DEVELOPMENT_STATE.md` for the exact checkpoint.

## Local requirements

- Godot 4.7.1 or a compatible Godot 4.x release
- JDK 17 and Android SDK components for Android export

## Source asset policy

The purchased CraftPix source kit is stored only in ignored `.source-kit/`. Runtime-used images may be copied into the project and are covered by the CraftPix commercial license; they are not CC0 and must not be redistributed as a standalone asset pack.
