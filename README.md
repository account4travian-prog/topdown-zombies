# TopDownZombies: a small game, kept small on purpose

A top-down zombie survival game built with AI coding help. It exists, it runs, and it taught me the basics of directing a game build end to end: spec, build, playtest, fix, repeat.

My role: design and acceptance; code by AI agents under my direction.

I'm keeping this entry short because the project is small, and padding it would say more about my marketing than my work. It's in the portfolio for one reason: it's an early, finished-enough thing, and the [Tithe and Turnip](https://github.com/account4travian-prog/tithe-and-turnip) line grew out of lessons from builds like this one. If you're evaluating my work, the evaluation projects in the hub will tell you more, this one is here so the record is complete, not because it's the headline.
