# TopDownZombies: a Godot game built from a prompt library

A top-down zombie game built in Godot by an AI coding agent working inside the project. It reached an Android export; no release or player data is recorded.

**My role:** design and acceptance; the code was produced by the agent under my direction.

The transferable part is the prompt library: the prompts that directed the build were kept in the project as artifacts and reused across sessions, and a standing development-state file let a new session resume from the project instead of from chat. The prompts are not reproduced here, so no claim is made about their content or quality.
